# Phase 4 Wave 2 PR A3 — SVG → ReportLab Drawing conversion for the
# white-label PDF cover. Customers upload an SVG logo, the cover renderer
# converts it to a Platypus flowable. ``svglib`` is the canonical bridge
# for this in the ReportLab ecosystem.
#
# Pinned ``<1.6`` because 1.6.0 added a hard dependency on
# ``rlpycairo`` (and transitively ``pycairo``), which requires the

# doesn't ship libcairo and the wheel build fails with
# ``Dependency "cairo" not found``. 1.5.x exposes the same
# ``svg2rlg`` API we use and pulls only ``lxml`` + ``cssselect2`` +
# ``tinycss2`` (pure-Python or pre-built wheels).
